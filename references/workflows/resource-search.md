# 个性化资源检索

目标：围绕当前问题，找到现在值得读或使用的论文、代码、权重、数据、教程或必要规范。适用于“按现状推荐”“找新研究”“补相关工作”；明确仅查 Zotero 时走 library。

## 形成检索问题

按 [研究上下文](../research-context.md) 确定本次补的是概念、方法证据、实现入口还是相关工作。从现有记录形成条件，无需用户重填档案。分清硬要求、优先偏好和未知项：缺代码可影响实践优先级，但不一概排除理论学习价值。

检索可围绕“CSI 预测如何压缩且保留跨场景能力”，不把 `wireless foundation model` 与 `compression` 当唯一关键词；按需扩展任务/方法同义词和引用链。导师推荐作者/团队可作入口，不当排他的质量标签。

## 来源与执行

1. 查本地库和已读记录，避免把已完成内容当新推荐；按新问题回读时说明目的。
2. 外搜优先论文官方出版/会议页及作者实现。通信问题考虑 IEEE Xplore 等通信来源；AI 方法按相关会议/出版平台检索，如 ACL Anthology、PMLR、OpenReview、CVF；arXiv 补预印本。正式发表、预印本、非学术教程分清，来源声誉不替代内容核验。
3. 可复用 `nature-academic-search` 的多源检索、去重和元数据核验，按问题改选来源，不机械沿用医学数据库排序。先检查当前工具/权限；不可用时用现有联网搜索查官方来源/公开接口。接口与访问条件使用时核验，不从旧文档假定已接通。
4. 区分搜索发现、元数据核对、摘要已读、全文已读、代码入口已核、实际运行已核。找到仓库不等于方法完整公开，下载页不等于数据已在本地；未运行不写“已复现”。
5. 按 DOI/arXiv/题名作者合并版本，正式版若改方法/结果则保留差异。引用量、年份、团队作辅助，不用固定排序公式。记录实际查询与覆盖范围，未找到不宣称没人做。

## 推荐与输出

先给少量最有用资源。每项包含可回查来源、解决哪个当前问题、推荐原因与阅读位置、前置条件、WFM 借鉴与限制、全文/代码核验状态。理论价值与当前可做性分开，未知算力/数据条件待核。

可按“现在优先／作为参照／暂缓”组织，说明暂缓原因；不把长列表全部变必读。需要 RIS/BibTeX 可复用转换工具；写入 Zotero 按具体授权，不为推荐自动批量入库。

交付前核对主要推荐的题名/作者/版本；理由依据实际已读内容；不把摘要猜测写成全文结论；不推荐用户已完成的起步工作。保存 Markdown 时可标 `zotflow_type: resource-search`，不套精读章节规范。
