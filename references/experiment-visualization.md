# 精读笔记中的实验图表

用于将论文关键实验表格转成便于快速理解的图表。先确定实验想回答的问题，再选数据和图型；无需把每张表、每个任务都重画。

## 选图依据

| 数据与阅读问题 | 优先图型 | 注意点 |
|---|---|---|
| 同条件下比较离散方法的性能或组件贡献 | 柱状图、点图；配对变化可用哑铃图 | 类别不具有连续顺序，不默认连线；突出主要基线与本文方法 |
| 位宽、样本量、可训练预算、剪枝强度等有序数值与性能的关系 | 折线图或点线图 | 使用真实横坐标；不把 2k、4k、full 等不等距点强行等距连接，full 无具体样本数时单独标注 |
| 性能与参数量、FLOPs、延迟等成本的取舍 | 散点图；配置有明确顺序时可连线 | 明确成本单位、优劣方向及参照；FLOPs 比不叫实测时延加速 |
| 多任务、多方法的对照 | 少量小面板或热图 | 指标尺度不同则分面；不混合 accuracy、相关系数、NMSE 求未经说明的平均 |
| 个体误差、权重或延迟等样本分布 | 直方图、箱线图 | 必须有个体样本、分箱频数或论文提供的分布统计；只有每方法均值时不用直方图 |
| 定性条件、方法特征或少量精确数字必须并排核对 | 紧凑表格 | 表格可以保留；不为了画图牺牲可读性 |

柱状图用于类别比较，直方图用于数值分布，两者按数据含义选择。若原论文已有清楚的曲线或消融图，可直接采用相关原图；密集或难读的关键数值表再转绘。

## 数据与比较口径

- 从 `read_mineru.py --table N` 或结构化正文提取精确数值，核对原 PDF 的表头、单位、方向与脚注。只选择支持主要结论的数据；说明“选取 Table N 的某组结果”，不伪装成全表。
- 选择公平的主要基线和本文方法，保留关键消融或反例。训练数据、学生规模、精度或预算不同会影响结论时，图注须指出，不能仅画对本文有利的结果。
- 保留绝对值与真实坐标；计算增益时注明参照，区分绝对分差、相对百分比和理论计算量比。柱状图基线通常从零开始，确需截断时显著标注；点图或差值图可用于呈现小差异。
- 原文有误差条才按原口径绘制，不虚构方差、样本、置信区间或未报告的值。数值缺失时跳过或用小表格解释，不从无刻度曲线估读成精确数字。
- 每张图都应能回答一个明确问题；轴、图例和文字要在笔记常用显示宽度下可读，避免大幅面密集拼图。

## 输出与叙述

采用可复现的绘图工具，例如 Python/Matplotlib；流程或损失关系图另用 `.drawio.svg`。自绘数据图默认只保留 `.svg`，临时预览、数据摘录和绘图代码放项目 `.build/`，不同时交付 PNG/PDF/TIFF 副本，也不在最终回复单独罗列配图。

图表嵌入相关实验解释处，沿用笔记的图片链接约定。图下注明“依据论文 Table N 转绘，非论文原图”，并保留原表或页码定位。可用如下短段落组织：

1. **实验问题与对照**：为什么安排这个基线、变量或消融。
2. **结果解读**：解释关键趋势及其与设计原因的联系，用必要数字支撑判断；篇幅以理解需要为准。
3. **结论范围**：结果支持什么，以及影响主要判断的限制。

同一数据不再以“图 + 完整原表 + 全部数值逐项复述”重复呈现。绘图后核对数值、单位与标注，并实际渲染检查文字、裁切和颜色；预览通过后，笔记仅链接最终 SVG。
